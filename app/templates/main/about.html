关于个人笔记

个人笔记是一个安静的个人写作角落：写下想法、存成草稿、需要时发布，并且只把某一条链接分享给想给的人。

它能做什么

  • 注册与登录，笔记默认只属于你自己；
  • Markdown 写作，左侧书写、右侧实时预览；
  • 草稿与发布两态，草稿不会出现在任何公开位置；
  • 分享链接可加密码、可随时取消，取消后链接立即失效；
  • 收藏、标签、搜索与评论。

技术栈

  • 后端：Python 3.12 + Flask，服务端渲染页面并就近提供 JSON 接口；
  • 数据库：SQLite（单文件 instance/notes.db）；
  • 前端：原生 HTML / CSS / JavaScript，不使用任何前端框架、CDN 或外部字体；
  • Markdown：Python-Markdown 渲染后经 nh3 白名单消毒。

两条硬性规范

  1. 后端统一返回 { "code": "...", "message": "中文提示" }，前端一律展示 message 里的中文提示。
  2. 依赖使用国内镜像安装，并在 requirements.txt 中锁定版本。

隐私

密码只保存哈希值；分享链接使用不可枚举的随机 token；上传只接受常见图片格式且限制在 2 MB 以内。
